왜 16dp인가

방 목록 14, 채팅 12, 설정 16·18, 프로필 20으로 화면을 오갈 때마다 콘텐츠 시작선이 흔들린다. 360dp 폭 기준 16dp는 카드·말풍선·그리드가 모두 여유 있게 앉는 최소 공통값이다.

세로 리듬

목록 계열은 12dp(카드 사이), 폼 계열은 24dp(섹션 사이)·8dp(라벨↔필드)로 두 가지 리듬만 사용한다. 18·14·7dp 같은 중간값을 없앤다.

반경의 위계

큰 면일수록 둥글다: 시트 20 > 카드·말풍선 16 > 셀·입력 12. 말풍선의 "말꼬리"는 한 귀퉁이만 4dp로 꺾는 기존 문법을 유지한다.

02-A · 채팅방 — 메시지 좌우 16 / 그룹 12 / 연속 4

통일 포인트

메시지 목록 좌우 12 → 16(서술 문단의 별도 좌우 8dp 제거 — 목록 패딩에 맡긴다), 연속 말풍선 2 → 4, 말풍선 반경 15 → 16, 본문 12.5 → 13.

상단 바

56dp 규격. 룸명(명조 15) + 테마 점 8 + 권한 라벨(마스터/참여자). 우측 ↓ = HTML 로그 내보내기, ⚙ = 방 설정. 배경 위 가독성 오버레이 45%.

GM 서술

다이스 카드

시간·수정됨

내 메시지는 말풍선 왼쪽, 상대는 오른쪽 하단에 시간 10sp. 수정된 메시지는 시간 위에 (수정됨) 9sp. 본인 메시지 길게 누르면 편집/삭제 메뉴(06 참조).

05-A · 방 설정 — 셀 간격 8 / 섹션 24

통일 포인트

섹션 제목·그리드·행의 좌우 기준선이 현재 16/18로 어긋나 있다 → 전부 16 한 줄로 정렬. 섹션 제목 위 18 → 24, 아래 10 → 8. 설정 행 상하 13 → 12.

선택 표시

테마 셀·배경 셀 모두 옐로 1.5dp 테두리 + 옅은 옐로 배경으로 동일하게. "사용 중" 배지는 배경 셀에만. 커스텀 배경을 쓰는 중이면 프리셋 뒤에 실제 이미지 썸네일 셀이 추가된다.

초대 코드

이미 발급된 코드는 부제에 노출하고 탭하면 큰 코드 다이얼로그(06). 미발급이면 탭 시 발급. 상대는 방 목록의 참여에서 입력.

권한

참여자에겐 동일 화면을 읽기 전용으로 보여주고 상단에 "마스터만 변경할 수 있습니다" 안내 밴드 1줄.
