# 코드 리뷰 2026-07-30 — 알림 진단 + 3회 루프 리뷰

요청: ① 알림이 오지 않는 문제 확인·수정, ② 3회 루프로 버그·치명적 문제를 리뷰하고
즉시 수정, 결과를 문서로 통합. 모든 수정은 이 문서 작성 시점에 코드에 반영·푸시됨.

---

## 1부. 알림이 오지 않는 문제 — 진단과 수정

### 실측 진단 (에뮬레이터 2대)

1. 수신 기기 앱을 홈으로 보낸 뒤(백그라운드) 상대 기기에서 메시지 전송.
2. 수신 기기 로컬 DB를 직접 확인 → **메시지 미도착**. Firestore 리스너는 붙어
   있었지만 OS가 백그라운드 앱의 네트워크를 중단해 전달되지 않음.
3. 로그에서 `ActivityManager: freezing … com.pbp.app` 확인 — 백그라운드 진입
   약 70초 뒤 **프로세스 동결**(Android 12+ cached app freezer). 동결 후에는
   리스너 스레드 자체가 멈춘다.

### 결론 — 원인 체인

- 백그라운드/종료 상태에서 알림을 띄울 수 있는 유일한 경로는 **FCM 푸시**다.
  (리스너 경로는 백그라운드에서 신뢰 불가 — 위 실측)
- 그런데 푸시 발송자인 **Cloud Functions(functions/index.js)가 아직 미배포**
  상태다. 따라서 현재 빌드에서는 백그라운드 알림이 구조적으로 올 수 없다.
- 클라이언트 단독으로는 해결 불가: FCM 발송에는 서버 자격(서비스 계정)이
  필요하고, 레거시 서버 키 API는 2024-06 폐지됨.

### 코드로 고친 것 (배포 시 바로 동작하도록)

| # | 문제 | 수정 |
|---|---|---|
| N-1 | `FcmService`가 "이 방 리스너가 붙어 있으면 알림 생략"(구 P2-2) — 백그라운드 리스너가 메시지를 전달하지 못함을 실측으로 확인, 푸시가 와도 알림이 안 뜨는 경우 발생 | 백그라운드면 리스너 유무와 무관하게 알림. 리스너 경로와 겹쳐도 알림 ID(방 해시)가 같아 하나로 교체될 뿐 중복 표시 없음 |
| N-2 | 상대의 '프로필 전환' 등 SYSTEM 메시지에도 알림 발생 | 리스너 경로(PbpApp)·functions 양쪽에서 SYSTEM 타입 제외 |
| N-3 | functions 파이프라인 정합성 검증 | 멤버 문서 키(auth UID) = 메시지 authorUid 기준 일치, admin SDK는 보안규칙 우회, package.json(node 20) 정상 — 배포만 하면 동작 |

### 남은 사용자 작업 (이것 없이는 백그라운드 알림 불가)

1. Firebase 콘솔에서 **Blaze 요금제** 활성화 (Functions 필수, 무료 한도 큼)
2. `npx firebase-tools login`
3. `npx firebase-tools deploy --only functions --project pbp-session-1195c`
4. 두 기기 모두 최신 APK 설치 후 테스트: 한 기기 앱을 완전히 종료 → 상대가
   메시지 전송 → 알림 도착 확인

참고: 앱이 **화면에 떠 있을 때** 알림이 없는 것은 의도된 동작(현재 보고 있는
대화)이며, 포그라운드 직후 잠깐의 백그라운드 구간은 리스너 경로가 알림을 띄운다.

## 2부. 루프 리뷰 — 발견 즉시 수정한 항목

### 루프 1 — 데스크톱 Main.kt·REST 클라이언트 (최근 변경 집중 구간)

| # | 심각도 | 문제 | 수정 |
|---|---|---|---|
| L1-1 | 상 | 기형 응답으로 `docId=""`인 메시지가 파싱을 통과하면 LazyColumn **중복 키 크래시** + docId dedup 오염 가능 | `listMessages`/`listMessagesSince`에서 빈 docId 문서 폐기 |
| L1-2 | 중 | 커스텀 배경을 **원본 그대로 복사** — 수십 MB 사진이면 매 실행 풀사이즈 디코딩(메모리·시작 지연) | 1600px 초과 시 다운스케일 후 JPEG(85) 저장 — 모바일 Images.kt와 동일 정책 |
| L1-3 | 하 | 배경 "파일 선택" 더블클릭 시 OS 파일 다이얼로그 중복 오픈 | picking 플래그로 재진입 차단 |

### 루프 2 — 모바일 최근 변경부·알림/동기화 경로

| # | 심각도 | 문제 | 수정 |
|---|---|---|---|
| L2-1 | 중 | (= N-2) SYSTEM 메시지 알림 노이즈 | 앱 리스너 경로·functions 양쪽 제외 |
| L2-2 | 하 | 방 목록 **미확인 배지**가 프로필 전환 등 SYSTEM 메시지도 집계 | `observeUnreadCounts`에서 `type != 'SYSTEM'` 제외 |

그 외 점검하고 이상 없음을 확인한 것: 참여자 GM 정리(전날 수정)의 시작 시 교정
멱등성, 판정 매크로 문자열의 다이스 파서 통과(`(?=\s|$)` 경계), HexColorDialog
HSV↔HEX 양방향 동기화, 테마색 파라미터 스레딩, Room 타입 컨버터와 SQL 문자열
비교 정합(`MessageType.name`).

### 루프 3 — 크로스컷팅 (리소스·보안·엣지) + 회귀 검증

| # | 심각도 | 문제 | 수정 |
|---|---|---|---|
| L3-1 | 하 | 커스텀 배경을 바꿀 때마다 이전 파일이 `~/.pbp-desktop/backgrounds/`에 **무한 누적** | 적용 시 교체된 파일이 다른 방에서 안 쓰이면 삭제(backgrounds 폴더 안의 파일만, canonical 경로 검증) |

점검하고 수용(수정 불필요 판단)한 것:

- **firestore.rules**: 메시지 update는 작성자 본인만, 삭제는 멤버 전체(로그 리셋
  요구사항) — 의도와 일치. 단 **아직 미배포**(사용자 작업, docs/firebase-security.md).
- **48dp 방 썸네일이 배경 원본 비트맵 재사용**: L1-2로 상한 1600px이 보장되어 수용.
- **데스크톱 아바타 캐시 무제한**: 1:1 앱 특성상 항목 수가 작아 수용.
- **알림 탭 시 방 딥링크 없음**(항상 방 목록): UX 개선 후보로만 기록.
- **API 키 소스 하드코딩(desktop)**: 저장소 비공개 전제 유지 + 규칙 배포 후
  콘솔에서 키 제한 예정(기존 계획과 동일).
- **릴리스 디버그 서명**: 사용자 지시로 보류 중(스토어/Play 등록 시 키스토어 전환).

## 검증

- `:app` 빌드 + 단위 테스트 **63/63** + `:desktop` 컴파일 통과
- 에뮬레이터 2대 스모크: 메시지 왕복 수신, 방 목록 미리보기·미확인 배지 정상
- 데스크톱 앱 재실행 확인 (배경 커스텀·팔레트 포함 빌드)
- FCM 경로(N-1·N-3)는 functions 배포 전에는 실기 검증 불가 — 배포 후
  "앱 완전 종료 → 상대 전송 → 알림" 시나리오로 확인 필요
