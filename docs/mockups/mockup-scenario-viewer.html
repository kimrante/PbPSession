④ 헤더 ⚙ 탭 — 뷰어 설정 창

시나리오 뷰어 — GM 전용
입력창 위 패널 UI 시안

위치: 입력 영역 위 도킹 — 입력 바와 한 면

플로트 창이 아니라 입력 영역 바로 위에 도킹되는 패널. chatBarBg 면이 입력 바와 이어져 한 덩어리로 보이고, 위쪽 경계만 line 1dp. 내부 gap3×gap4 (입력 영역과 동일 패딩). 오버레이가 아니라 채팅 목록이 패널 높이만큼 줄어드는 방식 — 마지막 말풍선을 가리지 않는다. 드래그 없음.

신규 수치 0개 — 전부 기존 규격 재사용

칩 = 판정 요청 칩과 동일 캡슐. 필드 = panel2 + rCell. 확인 버튼 = 전송 버튼과 같은 테마색 + rCell + 높이 40. 경고창 = 다이얼로그 한 가족. 패널 패딩 = 입력 영역과 동일.

① 진입 — 📖 시나리오 칩 (판정 왼쪽)

GM 프로필 활성 시 칩 행의 첫 번째 — 시나리오가 판정 칩보다 왼쪽(spacedBy(gap2)). 판정 칩 문구는 "판정"으로 축약("＋ 판정 요청" → "판정"). 패널이 열려 있는 동안은 시나리오 칩을 진하게(signature 32% 면 + signatureDeep 테두리) — 열림 상태 표시.

④ 뷰어 설정 창 — 헤더 ⚙ 진입

문서가 로드된 상태(Viewing)에서만 헤더에 ⚙(40dp 히트) 노출 — 링크 입력 상태에선 설정할 것이 없어 감춘다. 다이얼로그 한 가족 규격 (panel · rSheet · 타이틀 18sp 센터 · 닫기 signatureInk). 구성: 문서(현재 제목+링크 panel2+rCell 카드, "다른 문서로 바꾸기"·"처음부터 읽기" 탭 행 padding(gap3)) · 보기(토글 2종 — 캡처 설정 토글과 동일 부품 34×20: "읽은 문장까지 진하게" 기본 ON, "문단 단위로 보기" 기본 OFF). 토글 항목은 제안 — 확정 시 지시서에 반영.

헤더에 문서 제목 표시

문서를 불러오면 헤더 라벨이 📖 시나리오 → 📖 {문서 제목}으로 바뀐다(11sp bold inkDim, 1줄 ellipsis). 제목 소스: export 응답의 Content-Disposition: filename="제목.txt" 헤더 — 추가 요청 없이 얻는다(RFC 5987 filename*=UTF-8''… 우선 파싱). 제목을 못 얻으면 "시나리오"로 폴백.

② 문장 표시 (Viewing)

문장은 GM 서술과 같은 명조(Gowun Batang) 13sp, 행간 1.85, 센터 정렬(원칙 2), 상하 대칭 gap2. 긴 문장은 카드 내부 스크롤(최대 화면 1/3). 하단 행: ⧉ 복사(11sp signatureInk 텍스트 버튼) · 17 / 128(10sp inkDim 센터) · 우하단 ‹ › 40×40 pill(panel 면 + line 테두리). 경계에서 비활성 = inkFaint 면 + inkDisabled 글리프 (기존 비활성 버튼 토큰).

⧉ 복사 — 문장을 입력창으로

현재 문장을 클립보드에 복사하고 토스트 "문장을 복사했습니다" — GM이 입력창에 붙여넣어 서술로 보내는 워크플로. "다른 문서"는 하단 행에서 설정 창(④)으로 이동해 행이 복사·진행·이동 3요소로 단순해졌다. (참고: 시나리오 뷰어 구현 코드가 아직 원격에 없어 실코드 확인 불가 — 복사 동작의 정확한 사양은 구현 코드와 대조 필요.)

③ 경고창 (Failed)

다이얼로그 한 가족 규격 — panel · rSheet(20) · 타이틀 18sp 센터 · 본문 13sp · 확인 signatureInk. 문구 4종은 지시서 V5 확정문 그대로. 확인 → 링크 입력 상태로 복귀(입력값 보존).

상태·표시 규칙 (지시서 V4 준수, 위치만 개정)

패널 상태 3형: 링크 입력 → 로딩(같은 높이 유지, 스피너) → 문장. 닫기 ✕ ≠ 리셋 — 다시 열면 읽던 문장 유지, 다른 문서로만 초기화. GM 아닌 프로필로 전환·캡처 모드 진입 시 패널 숨김. 로딩 스피너 색은 테마색. 긴 문장은 패널 내부 스크롤(최대 화면 1/3) — 입력줄이 밀려나지 않게 상한 유지.

접근성·기타

✕·‹·›·확인 모두 히트 40dp. ‹ › contentDescription "이전/다음 문장". 패널은 chatBarBg(불투명 93%)라 배경 사진 위에서도 본문 대비 유지 — 입력 바와 동일한 접근(§6). 다크 모드는 토큰 스왑만으로 성립(chatBarBg·panel2·line 전부 토큰).
