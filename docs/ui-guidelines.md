# PbP UI 가이드라인 v1.1 (2026-08-02)

모든 신규 UI(모바일·데스크톱·목업)는 이 문서를 기준으로 만든다.
**UI/UX 문서는 3종 체계**이며 충돌 시 이 문서가 우선한다:

| 문서 | 역할 |
|---|---|
| **이 문서** (`docs/ui-guidelines.md`) | 규범 — 토큰·규격·원칙·화면 규칙 |
| `docs/mockups/final-design.html`(.png) | 최종 시안 — 규범을 적용한 최신 확정 스냅샷 |
| `docs/work-directive.md` | 작업 지시서 — 진행 중 작업 하나 (완료 시 내용 교체, 파일명 고정) |

구 문서(`PbP-design-spec.md`, `trpg-app-mockup-v2.html` 등 개별 목업,
디자인 감사 문서들)는 이 3종에 흡수·대체되어 삭제됐다. 코드 주석의
"스펙 N장"은 구 PbP-design-spec 장 번호 — 대응 규칙은 이 문서 9장에 있다.

---

## 1. 5원칙

1. **라이트 모드가 기준.** 새 화면·컴포넌트는 라이트로 먼저 설계하고,
   다크는 토큰 스왑(`PbpDarkColors`)으로만 파생한다.
   화면 코드에 `if (isDark)` 분기 금지 — 분기가 필요하면 그 색을 토큰으로 승격한다.
2. **센터 정렬이 기본.** 상단 바 타이틀, 빈 상태, 다이얼로그 콘텐츠, 대형
   표기(초대 코드 등)는 특별한 사유가 없는 한 가운데 정렬한다.
3. **상하 대칭 패딩.** 모든 padding/margin은 top=bottom. 항목 간 간격은
   `Arrangement.spacedBy` 또는 `Spacer`로 만들고, 한쪽 패딩으로 만들지 않는다.
   (유일 예외: 연속 말풍선 그룹 간격 — 코드 주석으로 명시할 것.)
4. **동류 컴포넌트는 같은 수치.** 같은 역할의 요소(카드끼리, 다이얼로그끼리,
   칩끼리, 아바타끼리)는 반드시 같은 토큰을 공유한다. "비슷한데 값이 다르면"
   둘 중 하나로 통일하는 것이 기본 동작이다.
5. **토큰 밖 수치 금지.** 아래 스케일에 없는 dp·sp·색은 쓰지 않는다.
   꼭 필요한 신규 수치는 먼저 `Tokens.kt`(데스크톱은 `Dimens.kt`)에 등재하고
   이 문서의 예외 목록에 한 줄을 추가한 뒤 사용한다.

## 2. 색

단일 출처: `app/ui/theme/Tokens.kt`(`PbpColors`) · 공유 팔레트는 `:shared Palette`.

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `bg` | `#F4F2EC` | `#0D1117` | 베이스 배경 |
| `panel` | `#FFFFFF` | `#161C24` | 카드·다이얼로그 면 |
| `panel2` | `#F7F4EC` | `#1D2530` | 보조 면(입력 필드 등) |
| `line` | `#14191F` 8% | `#FFFFFF` 8% | 구분선·테두리 1dp |
| `ink` / `inkDim` / `inkSub` | `#23272E` / `#6E7683` / 72% | — | 본문 / 보조 / 상단 바 부제 |
| `signature` | `#FFD05C` | `#FFD972` | 옐로 **면**(버튼 배경, 배지, FAB) |
| `signatureInk` | `#A3781A` | `#FFD972` | 밝은 면 위 옐로 **텍스트** |
| `onSignature` | `#1A1A1A` | 동일 | 옐로 면 위 글자 |
| `danger` | `#C94F4F` | `#FF6B6B` | 파괴적 동작 전용 |
| `themeDefault` | `#5F9EC7` | `#8EC5E8` | 방 테마 기본값 |
| `statBlue` | `#3B82F6` | 동일 | 값 치환·판정 성공 |

### 색 사용 규칙 (Do / Don't)

- **파괴적 동작(삭제·초기화·나가기)의 확인 버튼은 반드시 `danger`.**
  signature·signatureInk·하드코딩 빨강 전부 금지.
- **밝은 면 위 옐로 텍스트는 반드시 `signatureInk`.** 원색 `signature`는
  텍스트로 쓰지 않는다(대비 1.5:1). `signature`는 면 전용.
- **`Color(0x…)` 리터럴을 화면 코드에 쓰지 않는다.** 같은 값의 토큰이 있으면
  토큰을, 없으면 토큰을 새로 만든 뒤 쓴다. `Color.White`/`Color.Black` 알파
  변형도 동일 — 라이트 모드에서 흰색-알파는 배경과 구분되지 않는다.
- 선택 표시 링·체크는 `ink` 계열(라이트에서 보이는 색)로. 흰색 고정 금지.

### 색 리터럴 기능 예외 (이 목록 밖은 금지)

토큰으로 대체하면 **기능이 깨지는** 것만 예외다. 각 사용처에 `기능 예외(가이드 §2)`
주석을 달아 두었으므로, `Color(0x` grep 결과는 이 목록과 정확히 일치해야 한다.

| 위치 | 이유 |
|---|---|
| `Ui.kt` HSV 피커 · 데스크톱 `ProfileOverlays.kt` 피커 | 그라데이션·무지개가 **고르는 대상**이라 테마 스왑 대상이 아니다 |
| 데스크톱 `RoomListPane.kt` 앱 아이콘 d10 면 음영 | 브랜드 자산의 고정 값 |
| `notify/DesktopNotifier.kt` 트레이 아이콘 | AWT `Color`라 Compose 토큰을 쓸 수 없다 |
| `ChatScreen.kt` 채팅 배경 암전 | 상태 바까지 덮는 '무대의 암전'이지 면색이 아니다 |
| `ImageCrop.kt` 레터박스 | 사진 밖을 가리는 암전 |
- 판정 성공 = `statBlue`, 실패 = `danger`. 플랫폼·화면마다 다른 파랑/빨강 금지.

## 3. 타이포그래피

서체: 서술(내레이션)·워드마크 **Gowun Batang** / 대사·UI **Noto Sans KR**.

| 단계 | 크기 | 용도 |
|---|---|---|
| display | 18sp | 앱 타이틀, 다이얼로그 타이틀 |
| title | 15sp | 화면 제목, 카드 제목, 룸명 |
| body | 13sp | 본문, 말풍선, 서술, 빈 상태 안내문 |
| label | 11sp | 이름표, 섹션 라벨, 텍스트 버튼 |
| micro | 10sp | 시간, 배지, 아바타 이름표, "읽음" 등 메타 |

- 이 5단계 외의 sp 금지. **9sp·12sp·14sp·16sp는 폐기**(배지도 10sp).
- M3 기본값에 의존하지 않는다 — `Text`에 크기를 명시하고, AlertDialog 타이틀은
  18sp로 재정의한다(테마 오버라이드 권장). `fontSize` 미지정 금지(기본 14sp 유입).
- **장식 글리프 예외 목록** (텍스트가 아닌 아이콘·장식): 뒤로 `←` 20 ·
  인용 따옴표 24 · FAB `＋` 24 · 빈 상태 `🎲` 40 · 초대 코드 32.
  이 목록 밖의 새 크기는 금지. 양 플랫폼 동일 값.

## 4. 스페이싱 · 반경 · 고정 규격

4dp 그리드 6단계 — 이 밖의 여백 값은 쓰지 않는다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `gap1` | 4 | 밀착: 이름↔말풍선, 연속 말풍선, 배지 내부 상하 |
| `gap2` | 8 | 요소 기본 간격, 라벨↔필드 |
| `gap3` | 12 | 카드 사이, 그룹 사이, 리스트 상하 여백 |
| `gap4` | 16 | ★ 화면 가장자리(전 화면 공통), 카드 내부 |
| `gap5` | 24 | 섹션 사이 |
| `gap6` | 32 | 화면 하단 여유 |

| 반경 | 값 | 용도 |
|---|---|---|
| `rCell` | 12 | 그리드 셀, 입력 필드, 썸네일, 전송 버튼 |
| `rCard` | 16 | 카드, 말풍선, 패널, FAB |
| `rSheet` | 20 | 다이얼로그, 시트 (M3 기본 28 금지 — 테마 오버라이드) |
| `rTail` | 4 | 말풍선 꼬리 (전 플랫폼 공통) |
| pill | 999 | 칩, 배지, 토글, 아바타 |

고정 규격: 상단 바 56 · 터치 타깃 40 · 채팅 아바타 38 · 스트립 아바타 36 ·
헤더 오너 아바타 32 · 썸네일 48 · 로고 타일 22 · 테마 점 14(+bg색 3dp 링) ·
우측 사이드바 폭 264(`drawerWidth` — 화면 320 − 스크림 스트립 56).

## 5. 컴포넌트 규격

### 상단 바
높이 56 고정, 좌우 패딩 `gap2`. **타이틀 묶음은 화면 정중앙**(`titleInset`
계열로 좌우 동일 인셋 — 버튼 개수와 무관). 타이틀 15/워드마크 18, 부제 11.
아이콘 버튼은 40×40 pill.

### 카드 (방 카드 등 리스트 카드)
`panel` 배경 + `line` 1dp 테두리 + `rCard`. 내부 `padding(h=gap4, v=gap3)`.
카드 사이 `spacedBy(gap3)`, 리스트 contentPadding은 **상하 대칭**
(top=gap3, bottom은 FAB 겹침시 파생식 주석 명시).

### 필 · 칩 (알약형 소형 컨트롤) — 2단만 존재
- **표시용 필**(시스템 메시지, 잡담 표기, 다이스 결과): `padding(h=gap3, v=gap1)`
- **터치용 칩**(추천 칩, 토글, 소형 버튼): `padding(h=gap3, v=gap2)` +
  히트 영역 `heightIn(min=40)`
이 두 조합 외의 필 패딩 금지.

### 다이얼로그 — 한 가족
`panel` 배경 · `rSheet`(20) · 타이틀 18sp · 본문 13sp · 내부 여백 `gap5`,
콘텐츠 간격 `gap2`. 스톡 M3 AlertDialog를 쓸 때도 shape·색·타이틀 크기를
토큰으로 지정한다. 버튼: 확인 = `signatureInk`(파괴 동작은 `danger`),
취소 = `inkDim`. 탭 가능한 행은 `padding(gap3)` 통일.

### 버튼
- 주 버튼: `signature` 면 + `onSignature` 글자 + pill, 높이 ≥40.
- 텍스트 버튼: 11sp bold, 40 높이 pill, 좌우 `gap2`.
- FAB: 56×56, `rCard`, `signature` 면, -4° 회전(포스트잇 모티프 — 브랜드 예외).

### 배지 (미확인 수 등)
`signature` 면 + `onSignature` 10sp bold + pill, `padding(h=gap2-2…)` 대신
**min 18×18 원형 + 좌우 6** — 상하는 중앙 정렬로 자동 대칭.

### 입력 필드
`panel2` 면(또는 `line` 테두리) + `rCell`. 흰색-알파 배경 금지.
포커스 링은 `signature`.

## 6. 접근성

- 모든 탭 가능한 요소는 **터치 타깃 40dp 이상**. 시각 크기가 작아도
  히트 영역을 40으로 확장한다(`heightIn`/`minimumInteractiveComponentSize`).
- 텍스트 대비: 본문 4.5:1, 대형·bold 3:1 이상. 테마색 위 흰 글리프처럼
  대비가 3:1 미만이면 `nameColorForLight` 계열 보정 로직으로 잉크색 스왑.
- 배경 이미지 위 텍스트는 반드시 베일(`veil*`) 위에 얹는다.

## 7. 플랫폼 패리티 (모바일 ↔ 데스크톱)

- 데스크톱 고유 수치는 사이드바 280 · 본문 최대 폭 720 중앙 정렬 ·
  채팅 가장자리 24 **뿐이다**. 그 외 모든 색·여백·반경·글리프 크기는
  모바일 토큰과 같은 값을 쓴다.
- 같은 의미의 값이 플랫폼마다 다르면 버그로 취급한다.
- 팔레트·프리셋은 `:shared Palette` 단일 출처 — 플랫폼 로컬 사본 금지.

## 8. 신규 UI 체크리스트

새 화면·컴포넌트 PR 전에 확인한다:

- [ ] 라이트 모드로 먼저 그렸고, 화면 코드에 `isDark` 분기가 없다
- [ ] 모든 dp·sp가 4장 스케일 또는 예외 목록 안에 있다
- [ ] `Color(0x…)`·`Color.White`류 리터럴이 없다
- [ ] 모든 padding이 상하 대칭이다 (간격은 spacedBy/Spacer)
- [ ] 파괴 동작 버튼은 `danger`, 밝은 면 위 옐로 텍스트는 `signatureInk`
- [ ] 같은 역할의 기존 컴포넌트와 수치가 일치한다
- [ ] 탭 요소의 히트 영역이 40dp 이상이다
- [ ] 타이틀·빈 상태·다이얼로그가 센터 정렬이다
- [ ] 데스크톱에 같은 UI가 있다면 같은 값을 쓴다
- [ ] `final-design.html`에 해당 화면 프레임을 추가·갱신했다

## 9. 화면·기능 디자인 규칙 (구 PbP-design-spec 흡수, v0.12 현행화)

제품: **PbP** — 1:1 온라인 TRPG(Play by Post) 채팅 앱 (Android + 데스크톱).
레퍼런스 무드: ccfolia 모바일 — 배경 이미지 위 반투명 패널, 극장 톤. 전 구간 UTF-8.

### 화면 목록 (최종 시안 문서의 프레임과 대응)
방 목록 · 채팅방 · 프로필 전환 사이드바 · 캐릭터/오너 프로필 편집 · 방 설정 ·
대화 캡처 · 판정 요청 · 시나리오 뷰어(GM) · HTML 로그 내보내기(방 설정 진입) ·
푸시 알림. 앱 아이콘: 시그니처 옐로 바탕 중앙의 잉크색 d10 단독(무문자),
'포스트잇' 시안 확정 — 어댑티브(사각/원형) 대응.

### 채팅방 (구 스펙 4장)
- 상단 바: 좌 ←·? / 중앙 룸명+GM·PL 부제 / 우 ⚙·**현재 프로필 아바타**
  (내보내기는 방 설정 '공유·기타'로 이동 — v0.12.0)
- 배경: 방마다 이미지 지정 가능, 어떤 이미지든 가독성 베일(`veil*`) 자동
- 말풍선: 카카오톡형 좌우 정렬, 색·이름 색은 캐릭터 프로필 값, 프로필 이미지는 항상 원형
- **서술자(GM)**: 방 생성 시 자동 생성, 명조 서술 문단 출력, 발화 중 `" "` 안의
  문장만 분리해 일반 말풍선으로 (캐릭터 발화도 동일 규칙)
- 잡담 토글: ON 발신은 옅은 회색 비강조(점선) 말풍선. 수정/삭제 자유
- 프로필 교체: 상단 바 현재 프로필 아바타 탭 → 우측 사이드바 (단일 진입점 — 입력줄 스트립은 v0.16에서 제거)
- 텍스트 문법: 마크다운(`**굵게**` 등) + 루비(`(등대)[等臺]`) + `{값}` 치환

### 방/권한 (구 스펙 5장)
방 생성자 = 마스터(GM). 테마 컬러·배경 변경은 마스터 전용(타 참여자 읽기 전용 +
권한 안내). 테마 컬러 적용 범위: 전송 버튼, 강조선, 방 목록 인디케이터 등
포인트 UI — 말풍선 색과 무관.

### HTML 로그 내보내기 (구 스펙 6장)
진입: 방 설정 '공유·기타'. 출력: UTF-8 단일 HTML, 밝은 종이 톤.
보존: 원형 프로필 인장·이름(색)·시간·말풍선 색/좌우·GM 서술 스타일·잡담 회색(〔잡담〕).

### 알림 (구 스펙 7장)
앱 비활성 + 미확인 시 푸시. 형식 고정: 보낸 이 원형 아이콘 + 이름 +
"~님의 메시지가 도착했습니다." **채팅 본문은 어떤 경우에도 알림에 노출하지 않음**
(GM 서술 포함). 보낸 이 = 발화에 사용된 캐릭터 프로필 기준.
