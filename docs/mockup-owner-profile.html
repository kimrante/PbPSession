PbP 오너 프로필 설정 + 최근 사용한 색

두 가지 변경의 구현 지시서입니다. ① 오너 프로필을 기존 '프로필 편집' 화면과 같은 규격의 전체 화면으로 통일(개별 값은 미지원), ② 모든 프로필 설정 화면에 최근 사용한 색 줄 추가(색 네모 + 헥사 코드, 최대 3개).

규격 원칙 — 센터 정렬 기본 · 상하 여백 동일 · 동류 항목은 같은 여백값
01

오너 프로필 설정 화면

현재는 방 목록의 AlertDialog(OwnerProfileDialog)입니다. 이를 프로필 편집과 동일한 전체 화면으로 올려 상단 바(56dp) + 저장 캡슐 + 사진 블록 + 섹션 라벨 구조를 그대로 공유합니다. 오너는 캐릭터가 아니므로 캐릭터 값 섹션은 없습니다.

프로필 편집과 공유하는 규격

상단 바 56dp(좌 ← / 우 저장 캡슐) · 본문 좌우 16dp · 섹션 라벨 11sp 위 16dp·아래 8dp · 입력 필드 반경 12dp · 사진 원형 72dp + 골드 링. 라벨·필드는 기존 화면과의 통일감을 위해 좌측 정렬을 유지하고(폼 관례), 사진·미리보기 블록은 센터 정렬입니다.

차이점 — 캐릭터 값 없음

오너는 판정 주체가 아니므로 캐릭터 값 섹션과 {값이름} 치환을 지원하지 않습니다. 이름 색/말풍선 색을 따로 두지 않고 컬러 1개만 둡니다 — 잡담 말풍선과 아바타 배경에 함께 쓰입니다.

최초 실행 강제 상태 (01-B)

이름이 비어 있으면 뒤로 가기 비활성(← 28% 불투명) + 저장 캡슐 비활성 + 안내 밴드 1줄. 현재 OwnerProfileDialog(forced = !OwnerProfile.isSet)의 "닫을 수 없음" 규칙을 그대로 옮깁니다.

미리보기

캐릭터 편집의 미리보기(말풍선 색 확인)와 같은 자리·같은 규격. 오너는 잡담으로만 발화하므로 회색 점선 잡담 말풍선과 아바타를 보여줍니다. 이름 색은 컬러를 어둡게 낮춘 값(nameColorForLight 계열)으로 표시.

02

최근 사용한 색 (모든 프로필 공통)

칩 규격

색 네모 16×16dp 반경 4dp + 1dp 옅은 테두리(흰색 계열 색도 보이게) · 간격 6dp · 헥사 11sp 700 모노스페이스 #RRGGBB 대문자 · 칩은 캡슐(반경 999) 패딩 좌6/우10·상하4 · 칩 사이 6dp. 현재 선택 중인 색과 같으면 잉크색 테두리로 표시.

목록 규칙

전역 1개 목록을 모든 프로필·모든 색 슬롯이 공유합니다(요청: "모든 프로필 공통"). 최신순, 중복 제거, 최대 3개 — 4번째가 들어오면 가장 오래된 것이 밀려납니다. 비어 있으면 칩 줄 대신 회색 안내 문구 1줄(01-B 참조).

어떤 색이 쌓이는가

커스텀 색(HexColorDialog에서 적용한 색)만 기록합니다. 프리셋은 이미 위 줄에 항상 보이므로 기록하면 같은 색이 두 줄에 중복 노출됩니다. → 판단이 필요하면 리뷰에서 정해 주세요.

배치 위치

슬롯이 2개인 캐릭터 편집에서는 두 스와치 줄 아래에 한 번만 둡니다(줄마다 반복 금지 — 같은 목록이 두 번 보이는 낭비). 탭 대상은 마지막으로 만진 색 슬롯이고, 라벨 우측에 대상을 명시합니다(예: "탭하면 말풍선 색에 적용").

03

구현 지시 — 손댈 지점

현재 코드(main 기준) 기준의 반영 지점입니다. 모바일·데스크톱 모두 같은 규칙을 적용합니다.

대상현재변경
최근 색 저장 없음 신규 data/RecentColors.kt — OwnerProfile과 같은 SharedPreferences("pbp-settings")에 recentColors 키로 ARGB 목록을 CSV 저장. API: list: List<Long>(최신순), load(context), add(context, argb)(중복 제거 후 앞에 삽입, take(3)). 데스크톱은 AppConfig에 recentColors: MutableList<Long> 추가
기록 시점 HexColorDialog(onPick) 커스텀 색 적용 콜백에서 RecentColors.add() 호출 — 호출부는 ProfileEditScreen(customTarget 분기), OwnerProfileDialog(showCustomColor), RoomSettingsScreen(테마 컬러 커스텀). 방 테마도 색이므로 같은 목록에 쌓습니다
칩 UI 없음 신규 공용 컴포저블 ui/common/RecentColorsRow.kt — RecentColorsRow(selected: Long?, onPick: (Long) -> Unit). 세 화면이 같은 부품을 씁니다(동류 항목 통일)
오너 프로필 화면 RoomListScreen.OwnerProfileDialog (AlertDialog) 신규 ui/profile/OwnerProfileScreen.kt 전체 화면 + MainActivity NavHost에 "owner" 라우트 추가. RoomListScreen의 showOwner는 nav.navigate("owner")로 교체. 미설정 강제는 라우트 인자(owner?forced=true)나 OwnerProfile.isSet 검사로 처리하고 뒤로 가기(BackHandler)를 막습니다
오너 미리보기 없음 잡담 말풍선 1건 + 아바타. 잡담 색은 캐릭터와 무관하게 chatterBubble/chatterInk 토큰이므로 미리보기에서 바뀌는 것은 아바타 배경과 이름 색입니다 — 오해를 막기 위해 캡션을 "잡담 말풍선"으로 명시
데스크톱 Main.kt 오너 편집 오버레이 · AppConfig.ownerName/ownerColor/ownerImagePath 오버레이 내용을 같은 섹션 순서(사진 → 이름 → 컬러 → 최근 색 → 미리보기)로 맞추고 최근 색 줄 추가. PC는 창 크기가 넉넉해 전체 화면 전환 없이 오버레이 유지

기존 동작은 그대로

오너 프로필의 의미(잡담·참여 인사에만 사용, 프로필 스트립 미노출, 이 프로필로 발화 불가)와 저장 키(ownerName/ownerColor/ownerImagePath)는 변경하지 않습니다. 화면 형태와 색 선택 보조 UI만 바뀝니다.

확인 필요 — 2건

① 최근 색에 프리셋도 포함할지(현재 안: 커스텀만) ② 캐릭터 편집에서 최근 색 탭의 적용 대상을 "마지막으로 만진 슬롯"으로 할지, 아니면 슬롯별로 줄을 따로 둘지(현재 안: 한 줄 + 대상 명시).
