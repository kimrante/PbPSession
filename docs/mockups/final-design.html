문서 위상 — UI/UX 3종 체계

① 규범 = docs/ui-guidelines.md (토큰·규격·원칙) · ② 시안 = 이 문서 (규범을 적용한 최신 확정 스냅샷) · ③ 지시서 = docs/scenario-viewer-implementation.md (진행 중 작업). 과거 개별 목업(trpg-app-mockup 시리즈, mockup-* 단건들)은 이 문서로 통합·대체. 새 시안은 이 파일에 프레임을 추가·교체하는 방식으로 유지한다.

① 방 목록

브랜드 묶음 정중앙(titleInsetWide 112), 우측 Aa·참여·오너 아바타(32). 카드 = panel + line 1 + rCard, 내부 16×12, 썸네일 48 + 테마 점 14(+3 링, 우하단 3dp 돌출). 미확인 배지 = min 18×18 pill. FAB 56 · rCard · −4°(브랜드 예외).

② 채팅방 상단 바

좌 ←·? / 우 ⚙·현재 프로필(avatarBar 32 + 옐로 링 2) — 내보내기 ↓는 방 설정 '공유·기타' 행으로 이동(v0.12.0). 타이틀 묶음 정중앙 titleInset 96. 배경 이미지 위 barScrim.

③ 프로필 전환 사이드바

우측 드로어 drawerWidth 264, panel 면 + 좌측 rSheet 모서리, 스크림 38%. 행 = ManagerRow 규격(padding gap3 + rCell, avatarStrip 36 + 이름 15 + 태그 11). 활성 행 = signature 14% 면 + signatureInk + ✓. 행 탭 전환·길게 편집·바깥 탭 닫기.

④ 시나리오 뷰어 (GM 전용)

입력 영역 위 도킹 패널 — chatBarBg 한 면, 위 line 1dp. 칩 행: 📖 시나리오(첫 번째, 열림 시 진하게) · 🎲 판정. 헤더 = 📖 문서 제목 | ⧉(현재 문장을 입력창에 삽입) | ⚙(설정) | ✕. 문장 = 명조 13sp 행간 1.85 센터. 하단 = 진행 표시 + ‹ › 40 pill. 상세 사양은 지시서 V3~V5.

⑤ 다이얼로그 한 가족

모든 다이얼로그 공통: panel · rSheet 20 · 타이틀 18sp 센터 · 본문 13 · 내부 24 · 확인 signatureInk/파괴 danger · 취소 inkDim. 뷰어 설정 창 구성: 문서 카드(panel2+rCell) · 탭 행(gap3) · 보기 토글 2종(캡처 설정과 동일 부품 34×20).

수치 출처

이 문서의 모든 CSS 변수는 가이드 2~4장 토큰과 1:1 매핑 — 매직 넘버 없음. 구현과 시안이 어긋나면 가이드가 우선하고, 이 문서를 가이드에 맞춰 고친다.
