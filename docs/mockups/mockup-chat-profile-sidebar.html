① 상단 바: ⚙ 오른쪽 현재 프로필

아바타 avatarBar(32) + 활성 표시 옐로 링 2dp — 방 목록 헤더의 오너 아바타와 같은 규격(원칙 4). 히트 영역은 40dp로 확장. 프로필을 바꾸면 이 아이콘이 즉시 바뀌어 "지금 누구로 말하는지"가 화면 밖 스크롤 상태에서도 항상 보인다 (입력줄 스트립은 키보드·스크롤에 가려질 수 있음).

내보내기 ↓ 는 방 설정으로 — 인셋 그대로

로그 내보내기는 상단 바에서 빼고 방 설정 '공유·기타' 섹션의 행으로 이동. 우측이 2요소(⚙ 40 + 아바타 32 + 간격 = 84dp)가 되어 기존 titleInset(96)을 그대로 쓴다 — 신규 인셋 토큰 불필요, 타이틀 폭도 종전과 동일(360dp 기기 기준 168dp) 유지.

② 사이드바 규격 — 다이얼로그 한 가족

panel 면 · 좌측 모서리 rSheet(20) · 내부 24×16 · 타이틀 18sp 센터 · 행은 탭 행 규격 padding(gap3) + rCell (프로필 관리 다이얼로그 ManagerRow와 동일 — 원칙 4). 폭 drawerWidth = 264 (화면 320 − 스크림 스트립 56 = M3 모달 드로어 관례) 토큰 등재.

행 구성

아바타 avatarStrip(36) + 이름 15sp bold + 태그 11sp. 활성 행: signature 14% 면 + 40% 테두리 + 이름 signatureInk + ✓ — 판정 요청 칩과 같은 강조 문법. GM 행은 명조 "GM" 이니셜. 하단 구분선 뒤 ＋ 프로필 추가 (signatureInk — 프로필 관리 다이얼로그와 동일). 길게 누르면 편집.

기존 스트립과의 관계

입력줄 위 프로필 스트립은 유지 — 사이드바는 같은 전환 동작의 두 번째 진입점이다(스트립: 타이핑 중 빠른 전환 / 사이드바: 스크롤 중·프로필이 많을 때). 전환 로직·데이터는 InputZone의 onSwitch를 그대로 재사용.

동작

아이콘 탭 → 우측에서 슬라이드 인(스크림 38%). 행 탭 = 전환 후 닫힘, 바깥 탭·뒤로 = 닫힘. 행 길게 = 프로필 편집 화면. 데스크톱은 이미 우측 영역이 넓어 동일 개념을 팝오버로 적용 가능(별도 시안).
