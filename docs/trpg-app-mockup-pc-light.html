PbP PC(데스크톱) 목업 — 라이트 모드

데스크톱 앱(desktop/ 모듈)의 2패널 구조 — 좌측 방 목록 사이드바 + 우측 채팅 — 를 화이트 모드 토큰으로 정의한 목업. 스페이싱·타이포·반경은 모바일 v2 토큰을 그대로 쓰고, PC 전용 규격 3개만 추가한다.

원칙 — PbP의 기본 디자인은 항상 라이트(화이트) 모드다. 다크 모드는 토큰 스왑 파생.
PC

메인 창 — 방 목록 + 채팅

사이드바 280dp 고정, 채팅 본문은 최대 720dp로 중앙 정렬(초광폭에서 말풍선이 늘어지지 않게), 채팅 영역 가장자리는 24dp(모바일 16 → PC 24). 그 외 모든 값은 v2 토큰과 동일하다.

기본 디자인 = 라이트

PbP의 기준 디자인은 라이트 모드다. 신규 화면·목업은 라이트로 먼저 그리고, 다크 모드는 Tokens.kt 스왑 파생으로만 취급한다. 밝은 배경 위 옐로는 텍스트 #A3781A / 링 #E0B13E, 면(버튼)만 #FFD05C.

PC 전용 규격 3개

사이드바 280dp · 채팅 본문 최대 폭 720dp(중앙 정렬) · 채팅 가장자리 24dp. 말풍선 최대 폭은 420dp. 그 외 상단 바 56, 아바타 38/36, 반경 12/16/20, 타이포 5단계 전부 v2와 동일.

사이드바

모바일 방 목록 카드와 같은 부품. 현재 방은 테마 컬러 틴트 + 테두리로 표시(라이트 목업 01장 .roomcard.active). 하단 고정: 새 세션(옐로) · 코드로 참여(아웃라인). 모바일의 FAB·참여 버튼과 동일 위계.

채팅

배경은 아침 안개 등대 + 밝은 베일. 메시지 6종(서술·인용·좌우 말풍선·연속·다이스·잡담) 규칙과 입력 영역 3층 구조(스트립→추천→입력줄)는 모바일과 동일. PC는 Ctrl+Enter 전송 힌트를 입력줄에 상시 노출.
