PbP 오너 프로필 설정 + 최근 사용한 색

두 가지 변경의 구현 지시서입니다. ① 오너 프로필을 기존 '프로필 편집' 화면과 같은 규격의 전체 화면으로 통일(개별 값은 미지원), ② 모든 색 선택 줄(오너 컬러 · 이름 색 · 말풍선 색 · 방 테마 컬러)의 커스텀 버튼 뒤에 최근 사용한 색 5개를 스와치로 이어 붙임. 예시 프리셋은 3종으로 축소.

규격 원칙 — 센터 정렬 기본 · 상하 여백 동일 · 동류 항목은 같은 여백값
01

줄 구성과 규격

순서는 프리셋 3종 → 커스텀(＋) → 구분선 → 최근 5개로 모든 색 줄에서 동일합니다. 스와치는 원형 26dp(9개 + 구분선이 한 줄에 들어가는 크기 — 현행 32dp에서 축소) · 간격 4dp · 구분선 1dp × 높이 16dp(좌우 여백 2dp). 최근 스와치는 흰색 계열도 보이도록 안쪽 1dp 옅은 테두리를 넣습니다. 선택 중인 색은 위치와 무관하게 잉크색 아웃라인으로 표시합니다.

목록 규칙

전역 1개 목록을 모든 색 줄이 공유합니다(오너 컬러 · 이름 색 · 말풍선 색 · 테마 컬러). 최신순 · 중복 제거 · 최대 5개 — 6번째가 들어오면 가장 오래된 것이 밀려납니다. 커스텀 색을 어디서 적용해도 네 곳 모두에 즉시 나타납니다.

5개가 안 찼을 때 (01-B · 02-B) — 확정

빈 자리는 점선 빈 원으로 두어 줄 길이를 항상 고정합니다(동류 항목 여백 통일). 빈 원은 눌러도 아무 동작이 없어야 하며(리플·포커스도 없음), 하나도 없으면 구분선과 빈 원 5개만 보입니다.

배경은 제외

방 설정의 배경은 프리셋 그라데이션 또는 갤러리 이미지라 '색 하나'로 지정하는 값이 아닙니다. 따라서 최근 색은 테마 컬러에만 붙였습니다. 배경까지 단색 지정을 원하시면 별도 기능(단색 배경)이 필요합니다.

테마 컬러 그리드는 왜 줄로?

테마 컬러는 라벨("새벽 하늘")이 붙은 4열 그리드라, 최근 색 셀을 그리드에 끼우면 라벨이 빈 셀이 생기고 그리드가 2행 → 3행으로 늘어납니다. 그래서 그리드는 그대로 두고 바로 아래 같은 스와치 줄을 붙였습니다 — 다른 화면과 같은 부품·같은 규격입니다.

프로필 편집과 공유하는 규격

상단 바 56dp(좌 ← / 우 저장 캡슐) · 본문 좌우 16dp · 섹션 라벨 11sp(위 16·아래 8) · 입력 필드 반경 12dp · 사진 원형 72dp + 골드 링. 라벨·필드는 기존 화면과의 통일감을 위해 좌측 정렬을 유지하고(폼 관례), 사진·미리보기 블록은 센터 정렬입니다.

차이점 — 캐릭터 값 없음

오너는 판정 주체가 아니므로 캐릭터 값 섹션과 {값이름} 치환을 지원하지 않습니다. 이름 색/말풍선 색을 따로 두지 않고 컬러 1개만 둡니다 — 잡담 이름 색과 아바타 배경에 함께 쓰입니다.

최초 실행 강제 상태 (02-B)

이름이 비어 있으면 뒤로 가기 비활성(← 28% 불투명) + 저장 캡슐 비활성 + 안내 밴드 1줄. 현재 OwnerProfileDialog(forced = !OwnerProfile.isSet)의 "닫을 수 없음" 규칙을 그대로 옮깁니다.

미리보기

오너는 잡담으로만 발화하므로 회색 점선 잡담 말풍선을 보여줍니다. 잡담 말풍선 색 자체는 chatterBubble 토큰으로 고정이라, 컬러 변경으로 바뀌는 것은 아바타 배경과 이름 색입니다.

03

구현 지시 — 손댈 지점

현재 코드(main 기준) 기준의 반영 지점입니다. 모바일·데스크톱 모두 같은 규칙을 적용합니다.

대상현재변경
최근 색 저장 없음 신규 data/RecentColors.kt — OwnerProfile과 같은 SharedPreferences("pbp-settings")에 recentColors 키로 ARGB CSV 저장. API: list: List<Long>(최신순), load(context), add(context, argb)(중복 제거 후 앞에 삽입 → take(5)). 상한은 const val MAX = 5로 한 곳에서 관리. OwnerProfile처럼 mutableStateOf로 들고 있어야 적용 즉시 네 화면이 갱신됩니다. 데스크톱은 AppConfig.recentColors: MutableList<Long> 추가 + snapshot()에 포함
기록 시점 HexColorDialog(onPick) 커스텀 색 적용 콜백에서 RecentColors.add(). 호출부 3곳: ProfileEditScreen(customTarget 분기 — 이름/말풍선 공용), OwnerProfileDialog(showCustomColor), RoomSettingsScreen(showCustomTheme). 프리셋 선택은 기록하지 않습니다(위 줄에 이미 있어 중복)
스와치 줄 부품 ProfileEditScreen.SwatchRow (private) 공용으로 승격 ui/common/ColorSwatchRow.kt — ColorSwatchRow(presets, selected, onSelect, onCustom) 안에서 프리셋 → 커스텀 → 구분선 → 최근 5개(빈 자리는 점선 원)를 그립니다. 스와치 32dp → 26dp, 간격 8dp → 4dp. 네 화면(오너·이름·말풍선·테마)이 이 부품 하나를 씁니다. 큰 글꼴·좁은 화면에서 넘칠 수 있으니 Row → 가로 스크롤(horizontalScroll)로 감쌉니다
방 설정 테마 컬러 LazyVerticalGrid 4열 + ThemeCell(라벨 있음) 그리드는 그대로(2행 유지). 그리드 바로 아래에 ColorSwatchRow의 최근 색 부분만 재사용한 줄을 배치하고, 탭 시 vm.setThemeColor() 호출. 그리드 고정 높이(150.dp)는 변경 없음
방 설정 배경 프리셋 그라데이션 + 갤러리 이미지 변경 없음 — 색 하나로 지정하는 값이 아니라 최근 색 대상이 아닙니다(01-B 주석 참조)
오너 프로필 화면 RoomListScreen.OwnerProfileDialog (AlertDialog) 신규 ui/profile/OwnerProfileScreen.kt 전체 화면 + MainActivity NavHost에 "owner" 라우트 추가. RoomListScreen의 showOwner는 nav.navigate("owner")로 교체. 미설정 강제는 OwnerProfile.isSet 검사 + BackHandler로 뒤로 가기 차단
데스크톱 Main.kt SwatchRow(private) · 오너/프로필/방 설정 오버레이 데스크톱 SwatchRow에도 같은 순서로 최근 3개를 붙이고 AppConfig.recentColors를 읽습니다. PC는 창이 넉넉해 오버레이 형태 유지

기존 동작은 그대로

오너 프로필의 의미(잡담·참여 인사에만 사용, 프로필 스트립 미노출, 이 프로필로 발화 불가)와 저장 키(ownerName/ownerColor/ownerImagePath)는 변경하지 않습니다. 오너의 저장 키도 그대로입니다.

프리셋 축소 — 이름 색 · 말풍선 색만

PbpPalette.namePresets · bubblePresets를 5종 → 앞 3종으로 줄입니다(take(3) 아님, 목록 자체를 3개로). 오너 컬러는 bubblePresets를 그대로 쓰므로 함께 3종이 됩니다. 테마 컬러 7종은 유지 — 이름이 붙은 큐레이션 프리셋(새벽 하늘·라일락…)이라 '예시 색'과 성격이 다릅니다. 테마도 줄이길 원하시면 말씀해 주세요.
