## 1. 제품 개요
- 앱 이름: **PbP**
- 플랫폼: Android
- 1:1 사용 전제의 온라인 TRPG(Play by Post) 채팅 앱
- 레퍼런스 무드: ccfolia(코코포리아) 모바일 — 배경 이미지 위 반투명 패널, 극장 톤
- 인코딩: 전 구간 UTF-8

## 2. 디자인 토큰
| 토큰 | 다크 모드 | 화이트 모드 |
|---|---|---|
| 베이스 배경 | `#0D1117` | `#F4F2EC` |
| 패널 | `#161C24` | `#FFFFFF` |
| 시그니처 옐로 | `#FFD972` | `#FFD05C` |
| 테마 컬러(방별 가변, 기본) | `#8EC5E8` | `#5F9EC7` |
| 본문 잉크 | `#E8ECF2` | `#23272E` |
| 잡담 말풍선 | `rgba(255,255,255,.14)` | `rgba(20,25,32,.06)` |
- 서체: 서술(내레이션) **Gowun Batang(명조)** / 대사·UI **Noto Sans KR**
- 앱 타이틀 "PbP" 강조색: 다크 모드 = 시그니처 옐로, **화이트 모드 = 잉크 블랙(#23272E)**
- 다크 모드용 밝은 이름색은 화이트 모드에서 진한 색으로 치환
  (`#FFC46B→#C07B1F`, `#8EC5E8→#33719C`, `#FFD972→#8A6D1C`)

## 3. 화면 목록 (목업 섹션 번호와 동일)
1. **방 목록** — 방 카드(배경 썸네일 + 테마 컬러 점 + 미확인 옐로 배지), 방 생성 FAB
2. **채팅방(핵심)** — 아래 4장 참조
3. **캐릭터 프로필 편집** — 원형 이미지, 이름 색/말풍선 색 개별 지정 + 실시간 미리보기
4. **방 설정** — 마스터 전용: 테마 컬러 3종 + 커스텀 + 최근 사용한 색, 배경 이미지(프리셋+갤러리)
5. **HTML 로그 내보내기** — 종이 톤 문서, 형태 보존(아래 6장)
6. **푸시 알림** — 잠금 화면, 본문 비노출
7. **앱 아이콘** — 시그니처 옐로 바탕 중앙의 잉크색 d10 단독(무문자), 면 분할선은 배경 옐로.
   어댑티브 아이콘(사각/원형) 대응. 확정 시안: `app-icon-concepts.html`의 02 '포스트잇' (2026-07-29 개정)

## 4. 채팅방 핵심 규칙
- 좌상단: 룸명 + 테마 컬러 표시 / 우상단: **로그 내보내기 아이콘**, 방 설정 아이콘
- 배경: 방마다 이미지 지정 가능. 어떤 이미지든 가독성용 베일(다크: 어두운 / 화이트: 밝은)을 자동으로 덮음
- 말풍선: 카카오톡형 좌우 정렬. **말풍선 색·이름 색은 캐릭터 프로필 값**을 사용. 프로필 이미지는 항상 원형
- **서술자(GM)**: 방 생성 시 자동 생성되는 특수 프로필, 생성자가 권한 보유
  - GM 발화는 명조체 서술 문단으로 출력
  - 발화 중 `" "` 안의 문장만 분리하여 일반 말풍선으로 출력
- **잡담 토글**: 입력줄의 on/off 태그. ON 상태 발신 메시지는 내용과 무관하게 옅은 회색 비강조(점선) 말풍선
- **수정/삭제**: 모든 메시지 자유롭게 가능. 말풍선 옆 연필/휴지통 마이크로 버튼
- **프로필 교체 스트립**: 입력창 바로 위. 원형 아바타 가로 나열, 활성 프로필은 옐로 링. 1인 다프로필(NPC 등) 지원
- 텍스트 문법: 마크다운(`**굵게**`, `*기울임*` 등) + 루비 문자(`|等臺《등대》` 형식)

## 5. 방/권한
- 방 생성자 = 마스터(GM). 테마 컬러·배경 이미지 변경 권한은 마스터 전용(타 참여자는 읽기 전용 + 권한 안내 밴드)
- 테마 컬러 적용 범위: 전송 버튼, 강조선, 방 목록 인디케이터 등 포인트 UI (말풍선 색과는 무관)

## 6. HTML 로그 내보내기
- 진입: 채팅방 우상단 ↓ 아이콘, 방 설정 메뉴
- 출력: UTF-8 단일 HTML, 밝은 종이 톤
- **보존 요소**: 원형 프로필 인장, 이름(색 포함), 시간, 채팅 내용, 말풍선 색/좌우 형태, GM 서술 문단 스타일, 잡담의 회색 처리(〔잡담〕 표기)

## 7. 알림
- 앱 비활성 + 미확인 메시지 존재 시 푸시
- 형식 고정: **보낸 이 원형 프로필 아이콘 + 이름 + "~님의 메시지가 도착했습니다."**
- 채팅 본문은 어떤 경우에도 알림에 노출하지 않음 (GM 서술 포함)
- 보낸 이 표시는 발화에 사용된 캐릭터 프로필 기준

## 8. 구현 제안 (참고)
- 목업의 각 화면 옆 주석 카드(.notes)에 동작 규칙이 함께 적혀 있으므로, 구현 전 두 HTML을 열어 확인 권장
- 다크/화이트 모드는 디자인 토큰(2장) 스왑으로 구성되어 있어 테마 시스템 설계 시 그대로 매핑 가능
