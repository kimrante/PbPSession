바뀐 것 ① 리스트 상하 대칭 여백

리스트 contentPadding top 0 → gap3(12). 첫 카드가 상단 바에 밀착하던 문제 해소, 카드 사이 간격(12)과 같은 리듬 (원칙 3 '상하 대칭').

바뀐 것 ② 삭제 = danger

삭제 버튼 signature(옐로) → danger #C94F4F. 다이얼로그는 한 가족 규격: panel 면 · 반경 rSheet 20(M3 기본 28 아님) · 타이틀 18 · 본문 13 · 내부 여백 24 · 센터 정렬.

바뀐 것 ③ 오너 아바타 32

헤더 오너 아바타 30 → 32dp — 데스크톱과 동일 값으로 패리티 통일 (가이드 7장). 텍스트 버튼(Aa·참여)은 높이 40 히트 영역 유지.

바뀐 것 ④ FAB 반경 스케일 준수

18 → rCard 16. -4° 회전(포스트잇 모티프)은 브랜드 예외로 가이드 5장에 명문화. 테마 점은 좌표 하드코딩 대신 우하단 정렬.
