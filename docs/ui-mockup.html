PbP — 1:1 TRPG 채팅

③ 프로필 전환 바텀시트
  • 방별 활성 프로필“지금 누구로 말하는가”는 방마다 따로 기억됩니다. 방을 오가도 배역이 섞이지 않습니다.
  • GM은 항상 최상단진행자 프로필은 목록 맨 위 고정. 이 방 전용이라 다른 방에서는 보이지 않습니다.
  • 시트에서 바로 생성흐름을 끊지 않고 새 캐릭터를 만들어 즉시 전환할 수 있습니다.

06다이스봇 명령 사양

명령은 /r XdY 한 가지 문법으로 통일하고, 지원 면 수는 설정 목록으로 관리해 나중에 쉽게 추가합니다.

입력의미다이스봇 출력 예
/r 1d66면체 1개🎲 1d6 → 4
/r 1d1010면체 1개🎲 1d10 → 7
/r 1d100100면체 1개🎲 1d100 → 63
/r 2d66면체 2개 합산 (확장)🎲 2d6 → 3 + 5 = 8
